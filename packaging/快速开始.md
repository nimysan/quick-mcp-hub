# MCP Hub 快速开始

让 **Amazon Quick** 能读写你的邮箱、GitHub、Jira、金蝶云之家和 QQ。

填一次账号，Quick 里就多出一批可用的功能。**不需要装 Python、Node 或任何
运行时**，整个程序就是一个可执行文件。

---

## 一、装好，打开

**Windows（推荐装安装包）**

双击 `mcp-hub-*-setup.exe`，装完勾「立即运行」。以后从**开始菜单**的
MCP Hub 进。安装不需要管理员权限。

第一次运行 Windows 会提示「已保护你的电脑」（这个程序还没做代码签名）——
点 **更多信息 → 仍要运行**。

> **升级（已经装过一次）：先退出 Amazon Quick 再装。** Quick 运行时一直占用
> 着 `mcp-hub.exe`，安装程序替换不了它，会提示文件被占用。装完再把 Quick
> 打开。

**绿色版 / macOS / Linux**

解压，双击 `mcp-hub`（Windows 是 `mcp-hub.exe`）。

macOS 上第一次会被拦，在终端里对解压出来的文件夹执行一次：

```bash
xattr -dr com.apple.quarantine /path/to/mcp-hub
```

打开后会自己弹出一个配置窗口。没弹出来就在浏览器开
**http://127.0.0.1:7801** —— 同一个页面。它只在你自己的电脑上，
同一个网络里的其他人访问不到。

> Windows 上**没有黑窗口**。关掉配置页面程序仍在后台，托盘里有图标：
> 左键打开配置页面，右键给 打开配置页面 / 查看日志 / 退出。
> 再双击一次主程序也会把页面叫回来，不会报端口占用。

---

## 二、填上你的账号

页面中间「渠道市场」里点你要用的那个的「添加」。

点「**测试并保存**」：程序会先真的连一次，**连不通就不保存**，所以保存
成功就代表能用。

三件要知道的事：

- **密码只进系统自带的密码保管箱**（Windows 凭据管理器 / macOS 钥匙串），
  不写进任何文件、不出现在日志里。
- **会改东西的功能默认关着**。发邮件、建 issue、发消息这类，要手动勾
  「允许发信」/「允许写入操作」才会交给 AI。不勾的话 AI 根本看不到它们。
- 同一个系统可以配多个账号（两个邮箱、两个 GitHub），AI 用的时候指定哪一个。

几个要先去对方系统里拿东西的：

| 渠道 | 要填什么 |
|---|---|
| QQ 邮箱 | 邮箱地址 + **16 位授权码**（不是 QQ 登录密码）。网页版 → 设置 → 账号与安全 → 安全设置 → 开启服务 → 生成授权码 |
| GitHub | 用户名 + 个人访问令牌，或者点「连接」按钮授权 |
| Jira | 站点地址 + 邮箱 + API Token |
| 金蝶云之家 | 点「连接」扫码，不用找令牌 |
| QQ（本机 NapCat） | 要先装好 NapCat。表单顶部的「⚡ 自动配置」会替你开接口、生成令牌、把三个字段填好 |

## 三、接到 Amazon Quick

配置页面**最上面**那一节「🚀 快速接入 Amazon Quick」里，有**你这台机器上的
实际路径**和一段可以直接复制的配置。照它做：

```
Quick 里：Customize → Connectors → Add Local Connector → 选 Local
       → 把那段粘进去 → Test Connection 通了再点 Add
       → 最后点一次 Sync
```

Quick 给的是 Command / Arguments 两个输入框时：**Command 填路径，Arguments
填 `-serve`**，Environment variables 留空 —— 账号和凭据都已经在本机了，
不用在 Quick 里填任何密码。

> 路径请从页面上复制，不要手打。页面给的是**正在运行的那个程序**的路径，
> 所以你装在哪、挪到哪都是对的。

---

## 四、改了配置要让 Quick 重连

配置页面和给 Quick 用的服务是**两个进程**。后者在启动时读一次配置，所以你在
页面上新增或修改渠道之后，要让 Quick 重连一次：

**Connectors 里把它关掉再打开，然后点 Sync。**

---

## 五、出问题时

页面**右上角「查看日志」**，或者托盘图标右键 → 查看日志。把里面最后那段
发给维护者就够了 —— 它写着注册了哪些渠道、多少个功能、哪些功能因为开关
没开而没注册。

---

## 这个包里**没有**什么

- 没有任何账号、密码、令牌 —— 凭据只在你自己的机器上，由系统密码管理器保管
- 没有遥测、没有回传 —— 程序只连你自己配置的那些系统
