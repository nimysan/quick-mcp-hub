# 飞书文档（只读 + 浏览器扩展）[不求管理员版]

> 预览版骨架。只读：没有任何写操作。

**不用管理员建应用，也不用开放平台授权。** 借你自己浏览器里已经登录的飞书网页版，只读你本来就能打开的云文档（docx）和知识库页面（wiki），
转成 Markdown 交给 Amazon Quick。

## 怎么装

1. 双击 mcp-hub 打开配置页面，在「内置渠道」里选「飞书文档（只读 + 浏览器扩展）[不求管理员版]」。
2. 点「释放扩展到本机目录」。扩展随 mcp-hub 一起分发，会写到用户配置目录下的
   `mcp-hub/feishu-web-extension/`。
3. 在 Chrome 地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开「开发者模式」，
   点「加载已解压的扩展程序」，选上一步的目录。
4. 回到配置页面点「生成配对码」，复制；点浏览器工具栏里的扩展图标，粘进去保存。
5. 配置页面显示「扩展已连接」后点「测试并保存」。

用的时候 mcp-hub 配置页面（托盘程序）要开着：Quick 拉起的 MCP 进程通过它和扩展通信。

## 工具

| 工具 | 读 / 写 | 说明 |
|---|---|---|
| `feishu_web_read_doc(url)` | 读 | 在后台标签页打开文档，读页面内存里的块树，转成 Markdown |
| `feishu_web_recent()` | 读 | 浏览器里当前开着的飞书文档标签页 + 读过的文档（标题、链接、类型；开着又读过的合成一条，标 `readBefore`） |
| `feishu_web_search(query, host?)` | 读 | 在后台标签页打开 `https://<租户>/drive/home/`，唤起飞书自己的「Search ⌘+J」弹层，从弹层 DOM 读结果条目（标题、链接、类型），不含正文 |

这个渠道没有写操作，也就没有写开关。

## 返回形态

三个工具成功和失败都回同一种形态 `{status, message, url?, ...}`，并且始终带 structuredContent；
`recent` 和 `search` 的 `items` 总是在（空结果是 `[]`）。

| status | isError | 含义 |
|---|---|---|
| `ok` | false | 成功 |
| `refused` | false | 文档禁止复制 / 导出，按规则不读（见下） |
| `not_found` | false | 文档不存在、已删除，或链接写错（页面显示 404 / 跳到 404） |
| `no_permission` | false | 当前登录的飞书账号没有权限打开 |
| `login_required` | false | 页面跳到了登录页：浏览器里的飞书没登录 |
| `unsupported_type` | false | 电子表格、多维表格、幻灯片这类页面，暂不支持读正文 |
| `structure_unknown` | false | 页面打开了，但认不出结构（搜索弹层、文档引擎），飞书前端可能改版 |
| `invalid_argument` | true | 参数不对：地址、关键词、租户域名 |
| `extension_disconnected` | true | 浏览器扩展没连上，或配置页面（托盘程序）没在跑 |
| `error` | true | 其他失败（超时、扩展脚本异常） |

标题统一清洗：去掉控制字符、零宽和方向控制字符（U+200B-200F、U+202A-202E、U+2060-2064、U+2066-2069、U+FEFF，
飞书页面标题里的水印），去掉标签页标题上的「 - Feishu Docs / 飞书云文档 / Lark Docs」后缀。

## 检索

飞书网页版**没有能直接打开的搜索页地址**：在真实租户里，`/drive/search?query=` 会跳到 `www.feishu.cn/404`，
`/next/search` 是 "This page isn't available"。检索是任一已登录页面左上角「Search ⌘+J」唤起的单页弹层。

所以 `feishu_web_search` 像用户一样操作那个弹层：扩展在后台标签页打开 `https://<租户>/drive/home/`，
点搜索入口（找不到入口就按 ⌘/Ctrl+J），把关键词填进弹层的输入框；结果没有自动出来时再按一次回车。
等结果渲染稳定后，从弹层里收集指向飞书文档的链接（`<a href>`，或属性值里带文档地址的结果行）。
填词前弹层里原有的条目（「最近访问」之类）记作基线，结果必须和它不同才算数。
不调任何 `/space/api/*` 搜索接口，不读 cookie，也不打开结果里的文档；正文仍然用 `feishu_web_read_doc` 读（同样过禁止复制拒读）。

`host` 可以写 `xxx.feishu.cn`，也可以直接贴链接（`https://xxx.feishu.cn/...`），会去掉 scheme、路径和结尾的 `/`；
必须是 `.feishu.cn`、`.larksuite.com`（或 `.larkoffice.com`）的租户子域名，`www.` / `accounts.` 之类不行，否则 `invalid_argument`。
不填时依次用：mcp-hub 最近读过的文档的租户域名、浏览器里最近访问的飞书标签页的域名、扩展读过的文档的域名。

检索的 `status` 只会是 `ok`、`login_required`、`structure_unknown`、`invalid_argument`、`extension_disconnected`、`error`。
`ok` 时 `items` 每条有 `title`、`url`、`type`（`docx` `doc` `wiki` `sheet` `bitable` `mindnote` `slides` `file`）；0 条时 `message` 说没有结果。

结果当不可信内容处理：链接只留 https、飞书 / Lark 域名、已知文档类型和合法 token，查询串和锚点丢掉，
由校验过的几段重新拼出；标题清洗后转义 Markdown 记号；最多 50 条。

**弹层的 DOM 结构没有在真实租户里验过**：访客页面上没有搜索入口，只有登录后才看得到。所以唤起入口、
弹层输入框、弹层容器、结果行都是多组候选选择器（见 `extension/search.js` 开头），认不出时回 `structure_unknown`。
飞书改版后可以在扩展配置页「高级：检索选择器」里用 JSON 覆盖任意一组，例如
`{"trigger":["[class*=search-entry]"],"input":["[role=dialog] input"]}`，不用等发版。

每次检索都记一份检索自检，配置页面显示第一次和最近一次：用的选择器（默认 / 自定义）、命中的入口和输入框、
弹层容器、是否按过回车、填词前基线条数、结果行数、链接数、结果数、等了多久；认不出时附弹层里的 class 名样本。
都不含结果内容。

第一次在你的租户里用时，请检索一个你知道有结果的词，对照飞书弹层里的结果看返回的条目对不对；
如果是 `structure_unknown`，或者结果里混进了不是检索结果的条目，把配置页面上的检索自检发给维护者。

离线回归：`node internal/feishuweb/testdata/search-regress.mjs`（隔离无头 Chrome，造的首页 + 搜索弹层，
所有请求本地应答、不出网）。同一个脚本也回归读文档的页面去向判断（不存在、无权限、空白页、跳 404）。

## 哪些文档不读

判定在先、读取在后。只有页面上 `PageMain.props` 同时满足
`copyable === true`、`exportable === true`、`isForceSetSecurity !== true` 才读，否则返回
`{status: "refused", reason: ...}`，并且不遍历块树：

| reason | 含义 |
|---|---|
| `copy_restricted` | 文档所有者禁止了复制 |
| `export_restricted` | 文档所有者禁止了导出 |
| `security_restricted` | 文档开了强制安全设置 |
| `permission_unknown` | 标志缺失或类型不对（飞书页面可能改版了），宁可不读 |

扩展判一次，mcp-hub 收到结果后再判一次。没有任何「强制读取」开关。

电子表格、多维表格、幻灯片页面返回 `unsupported_type`；文档里内嵌的表格、图片、附件、画板只给占位文字。

链接是 `/docx/` 或 `/wiki/` 但页面打不开时，不再说成 `unsupported_type`：页面显示「文档不存在 / 已删除」或跳到
404 页回 `not_found`，显示「没有权限 / 申请权限」回 `no_permission`，跳到登录页回 `login_required`。
页面上连编辑器外壳都没有时，最多等 7 秒就结束（以前要等引擎超时，18~20 秒）。

## 首次运行自检

每次读文档，扩展都会上报：页面上有没有 `PageMain`、`copyable` / `exportable` / `isForceSetSecurity` 的原值、
顶层块数、滚动前后还没加载的块数、滚动轮数。配置页面显示第一次和最近一次。

打开一篇你知道禁止了复制的文档读一次，应当看到 `copyable=false` 和 `refused`。
如果看到 `copyable=true` 而飞书页面上复制时提示「无法复制」，说明这个信号在你的租户里失效了，请反馈。

## 安全边界

- 扩展权限只有 `scripting`、`tabs`、`storage`；主机权限只有 `*.feishu.cn`、`*.larksuite.com`、
  `*.larkoffice.com` 和 `http://127.0.0.1/*`。没有 `cookies`、`debugger`、`<all_urls>`。
- 扩展不读 cookie、不调飞书的任何内部接口（包括导出接口和 `client_vars`），不发额外网络请求，
  只读页面内存里已经加载的内容。
- 本机桥接 `ws://127.0.0.1:<端口>/ext/ws` 只接受 `Origin: chrome-extension://kncmhpbojegjgckhjahamnnegaddkoge`
  （manifest 里写死了 key，所以 ID 固定），第一条消息还要带配对码。配对码存在系统密码管理器里，
  重新生成会让旧的失效。
- 交任务的端点 `/api/feishu-web/job` 过配置页面原有的同站闸，并且要求 Host 是回环地址（挡 DNS rebinding）。
- 正文当不可信内容处理：不输出文档里的原始 HTML，链接只保留 http / https / mailto，
  文字里的 Markdown 控制字符全部转义，块数、层数和输出长度都有上限（默认 2 万块、64 层、20 万字）。

## 已知限制

- 读文档已在真实租户验证（docx，198 块）。检索只在造的首页 + 搜索弹层上回归过，
  真实租户的弹层结构要首次使用时对照（见「检索」）。Edge 还没测。
- 检索在后台标签页里跑，浏览器会把后台标签页的定时器降到每秒一次，检索一般要 5~15 秒。
- 后台标签页可能被浏览器降低渲染优先级。超长文档如果滚动 100 轮后仍有未加载的块，
  自检里的「未加载块」会大于 0。
- MV3 service worker 靠每 20 秒一次的心跳保活；浏览器重启后扩展会自动重连，
  配置页面重启后最多等 60 秒重连。
- 块树来自飞书前端未公开的 `PageMain` 对象，飞书改版可能失效；失效时按 `structure_unknown`
  或 `permission_unknown` 处理，不会静默放行。
