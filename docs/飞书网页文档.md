# 飞书网页文档（浏览器扩展）

> 预览版骨架。只读：没有任何写操作。

借你自己浏览器里已经登录的飞书网页版，读你本来就能打开的云文档（docx）和知识库页面（wiki），
转成 Markdown 交给 Amazon Quick。不需要建飞书应用，也不需要开发者权限。

## 怎么装

1. 双击 mcp-hub 打开配置页面，在「内置渠道」里选「飞书网页文档（浏览器扩展）」。
2. 点「释放扩展到本机目录」。扩展随 mcp-hub 一起分发，会写到用户配置目录下的
   `mcp-hub/feishu-web-extension/`。
3. 在 Chrome 地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开「开发者模式」，
   点「加载已解压的扩展程序」，选上一步的目录。
4. 回到配置页面点「生成配对码」，复制；点浏览器工具栏里的扩展图标，粘进去保存。
5. 配置页面显示「扩展已连接」后点「测试并保存」。

用的时候 mcp-hub 配置页面（托盘程序）要开着：Quick 拉起的 MCP 进程通过它和扩展通信。

## 工具

| 工具 | 读 / 写 | 说明 |
|---|---|---|
| `feishu_web_read_doc(url)` | 读 | 在后台标签页打开文档，读页面内存里的块树，转成 Markdown |
| `feishu_web_recent()` | 读 | 浏览器里当前开着的飞书文档标签页 + 扩展读过的文档（只有标题和链接） |
| `feishu_web_search(query, host?)` | 读 | 在后台标签页打开云空间搜索页 `https://<租户>/drive/search?query=…`，从页面 DOM 读结果条目（标题、链接、类型），不含正文 |

这个渠道没有写操作，也就没有写开关。

## 检索

`feishu_web_search` 只用飞书自己的搜索页：扩展打开 `https://<租户>/drive/search?query=<关键词>`，
等页面把结果渲染出来，收集页面里指向飞书文档的链接。不调任何 `/space/api/*` 搜索接口，不读 cookie，
也不打开结果里的文档；正文仍然用 `feishu_web_read_doc` 读（同样过禁止复制拒读）。
页面没有按地址里的关键词自动检索时，扩展把关键词填进页面自己的搜索框并按回车，和手动检索一样。

`host` 不填时，用浏览器里开着的飞书页面或读过的文档的域名。

| status | 含义 |
|---|---|
| `ok` | `items` 里是结果，每条有 `title`、`url`、`type`（`docx` `doc` `wiki` `sheet` `bitable` `mindnote` `slides` `file`）；0 条时 `message` 说没有结果 |
| `login_required` | 搜索页跳到了登录页：浏览器里的飞书没登录 |
| `structure_unknown` | 搜索页打开了，但认不出结果列表（飞书改版或租户页面不同） |
| `no_host` | 没给 `host`，浏览器里也没有开着或读过的飞书页面 |

结果当不可信内容处理：链接只留 https、飞书 / Lark 域名、已知文档类型和合法 token，查询串和锚点丢掉，
由校验过的几段重新拼出；标题去掉控制和零宽字符，转义 Markdown 记号；最多 50 条。

**结果列表的 DOM 结构没有在真实租户里验过**：搜索页要登录才有，开发时只能用访客身份打开公开站点
（waytoagi.feishu.cn），`/drive/search` 和 `/wiki/search` 都直接跳登录页，公开知识库页面上也没有给访客的搜索框。
所以提取不依赖具体 class 名：优先取结果区容器（class 同时含 search 和 result / list，或 `role=list` 一类）里的文档链接，
跳过侧栏和顶栏；认不出时回 `structure_unknown`。每次检索都记一份检索自检（登录与否、有没有搜索框、
用了哪种策略、链接数、结果数、等了多久；认不出时附结果区附近的 class 名样本，不含内容），配置页面显示第一次和最近一次。

第一次在你的租户里用时，请检索一个你知道有结果的词，对照飞书页面上的结果看返回的条目对不对；
如果是 `structure_unknown`，或者结果里混进了「最近访问」之类不是检索结果的条目，把配置页面上的检索自检发给维护者。

离线回归：`node internal/feishuweb/testdata/search-regress.mjs`（隔离无头 Chrome，造的搜索页，所有请求本地应答、不出网；
加 `--live` 另测公开站点的访客跳登录）。

## 哪些文档不读

判定在先、读取在后。只有页面上 `PageMain.props` 同时满足
`copyable === true`、`exportable === true`、`isForceSetSecurity !== true` 才读，否则返回
`{status: "refused", reason: ...}`，并且不遍历块树：

| reason | 含义 |
|---|---|
| `copy_restricted` | 文档所有者禁止了复制 |
| `export_restricted` | 文档所有者禁止了导出 |
| `security_restricted` | 文档开了强制安全设置 |
| `permission_unknown` | 标志缺失或类型不对（飞书页面可能改版了），宁可不读 |

扩展判一次，mcp-hub 收到结果后再判一次。没有任何「强制读取」开关。

电子表格、多维表格、幻灯片页面返回 `unsupported_type`；文档里内嵌的表格、图片、附件、画板只给占位文字。

## 首次运行自检

每次读文档，扩展都会上报：页面上有没有 `PageMain`、`copyable` / `exportable` / `isForceSetSecurity` 的原值、
顶层块数、滚动前后还没加载的块数、滚动轮数。配置页面显示第一次和最近一次。

打开一篇你知道禁止了复制的文档读一次，应当看到 `copyable=false` 和 `refused`。
如果看到 `copyable=true` 而飞书页面上复制时提示「无法复制」，说明这个信号在你的租户里失效了，请反馈。

## 安全边界

- 扩展权限只有 `scripting`、`tabs`、`storage`；主机权限只有 `*.feishu.cn`、`*.larksuite.com`、
  `*.larkoffice.com` 和 `http://127.0.0.1/*`。没有 `cookies`、`debugger`、`<all_urls>`。
- 扩展不读 cookie、不调飞书的任何内部接口（包括导出接口和 `client_vars`），不发额外网络请求，
  只读页面内存里已经加载的内容。
- 本机桥接 `ws://127.0.0.1:<端口>/ext/ws` 只接受 `Origin: chrome-extension://kncmhpbojegjgckhjahamnnegaddkoge`
  （manifest 里写死了 key，所以 ID 固定），第一条消息还要带配对码。配对码存在系统密码管理器里，
  重新生成会让旧的失效。
- 交任务的端点 `/api/feishu-web/job` 过配置页面原有的同站闸，并且要求 Host 是回环地址（挡 DNS rebinding）。
- 正文当不可信内容处理：不输出文档里的原始 HTML，链接只保留 http / https / mailto，
  文字里的 Markdown 控制字符全部转义，块数、层数和输出长度都有上限（默认 2 万块、64 层、20 万字）。

## 已知限制

- 只在 Chrome 157 的隔离无头模式下对公开文档回归过；Edge、真实租户都还没测。检索只在造的搜索页上回归过，
  真实租户的搜索页结构要首次使用时对照（见「检索」）。
- 后台标签页可能被浏览器降低渲染优先级。超长文档如果滚动 100 轮后仍有未加载的块，
  自检里的「未加载块」会大于 0。
- MV3 service worker 靠每 20 秒一次的心跳保活；浏览器重启后扩展会自动重连，
  配置页面重启后最多等 60 秒重连。
- 块树来自飞书前端未公开的 `PageMain` 对象，飞书改版可能失效；失效时按 `engine_missing`
  或 `permission_unknown` 处理，不会静默放行。
